Mate Maticos

API REST para gestionar el catálogo de la tienda: categorías y productos. El servidor está funcionando y listo para recibir peticiones.

Categorías

  • GET/categorias
  • POST/categorias
  • GET/categorias/{id}
  • PUT/categorias/{id}
  • DELETE/categorias/{id}

Productos

  • GET/productos
  • POST/productos
  • GET/productos/{id}
  • PUT/productos/{id}
  • DELETE/productos/{id}

Con {id}, GET devuelve un registro, PUT lo actualiza y DELETE lo elimina.

Hecho con Go, PostgreSQL y sqlc.
